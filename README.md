# network-security-labs
Network and security engineering practice projects

## 1. 프로젝트 소개
학교에서 배운 네트워크 구축 기술을 직접 실습하고, 그 과정과 결과를 기록 하기 위해 만들었습니다.

## 2. 학습 목표
- Packet Tracer를 활용한 지사 간 네트워크 연결
- RIP 라우팅을 이용한 네트워크 간 통신
- DHCP를 통한 IP 주소 자동 할당
- HTTP 및 DNS 서버 기능 이해와 동작 검증
